# 真实高校数据源接入说明

## 可选历史真实源模板

- 北京大学计算机学院通知公告
- 上海交通大学计算机学院学生事务通知

模板目录：

`config_templates/real_sources/`

这些模板用于手工验证旧的通用通知采集能力，不再作为 C9 校级研究生招生公告主演示链路的默认种子数据。默认启动不会自动导入这些模板；如需验证旧模板，可手动运行导入脚本。

## 当前推荐接入方式

当前项目已经具备“受控选源智能体 -> 候选校验 -> 受控采集”的主路径。

因此接入真实高校时，建议优先按下面顺序进行：

1. 先用自然语言工作台触发 source discovery
2. 看 `candidate_rankings`、`agent_trace`、`failure_reason`
3. 对稳定列表页或栏目页做保存/确认
4. 只有在 source discovery 明显找不到时，才手工导入模板

## 模板导入方式

```powershell
.\.venv\Scripts\python.exe scripts\seed_real_sources.py
```

脚本会按名称做 upsert：

- 不存在则创建
- 已存在则更新配置

## 规则说明

### 1. 静态列表页

适用于北大这种直接在 HTML 中输出通知列表的页面：

- `list_pages` 指向列表页 URL
- `item_selector` 指向每条通知容器
- `title_selector`、`link_selector`、`date_selector` 从容器中取值

### 2. 动态列表接口

适用于上交这种通过官方接口返回 JSON，再由前端渲染列表的页面：

- `request_method`：例如 `POST`
- `request_data`：接口表单参数
- `response_json_key`：返回 JSON 中承载 HTML 片段的字段
- 其余选择器仍针对 HTML 片段编写

## 新增真实站点建议

1. 先确认目标页是否公开访问
2. 优先找官方招生入口页、栏目页或列表页，不要先抓复杂登录页
3. 尽量选择：
   - 列表结构清晰
   - 详情正文区稳定
   - 附件链接明确
   - 不是单篇正文页、附件页或统计汇总页
4. 先在模板目录新增 JSON，再通过管理台或脚本导入
5. 先做一次手动任务验证，再开启定时调度

## 验证流程

1. 在自然语言工作台输入真实需求
2. 检查候选是否优先返回稳定 source，而不是 detail page
3. 如有需要，导入模板或手工补录
4. 在“数据源管理”确认状态为 `active`
5. 在“任务中心”手动执行一次
6. 在“文档中心”检查是否入库
7. 在“证据与日志”确认正文和附件抽取是否合理
