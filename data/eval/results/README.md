## 口径说明

- 全部样例在 `MOCK_LLM_ENABLED=true` / 无 API Key 的规则回退链路上运行，用于稳定回归，不代表在线 DeepSeek 效果。

- 无证据拒答专门检查不相关问题不会被强行绑定到任意招生公告。
- 本评测不访问真实高校网站；真实站点波动、反爬和页面改版需要单独在线回归。
